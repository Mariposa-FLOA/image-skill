# FLOA Mariposa visual language map

This reference turns the maintainer's supplied poster set into reusable design decisions. It records repeated relationships, not a layout catalogue. A new result must still be derived from its own source image and brief.

## Core proposition

FLOA Mariposa is a product identity expressed through a neo-editorial visual language. It is contemporary in its graphic control and open-ended in its subject matter. The visual world can move between a clean flat plane, a cinematic light event, a printed collage, a screen-like signal field, or an architectural metaphor while keeping the same confidence of scale and hierarchy.

Do not market the system as simply “vintage.” Print wear is one optional finish. Do not market it as simply “Y2K,” “cyberpunk,” or “collage.” Those are narrow branches, not the product's overall language.

## Repeated signals in the sample set

### Scale and type

- One oversized word or short phrase often becomes the largest physical mass in the composition.
- Type may behave like a wall, horizon, doorway, poster architecture, or a field that a silhouette interrupts.
- Small copy is sparse and aligned to an edge, beam, bar, image boundary, or intentional quiet zone.
- The strongest pieces do not need fake metadata to look designed.

### Image and metaphor

- People are often reduced to a silhouette or held in a simple, legible gesture.
- Objects such as a telephone, microphone, film strip, sign, or shoe can carry a communication, performance, or movement idea.
- Architecture, stairs, roads, windows, beams, and horizons are useful because they create direction and scale.
- A face, figure, or object can be divided by a measured grid or aperture when the division reinforces the idea rather than merely decorating it.
- Select one event per piece: signal, threshold, connection, movement, performance, or becoming.

### Colour and value

The most reusable colour roles are:

| Role | Typical family | Function |
| --- | --- | --- |
| Ink | near-black, charcoal, deep navy | text, silhouette, structural weight |
| Paper | warm ivory, bone, pale sand | breathing room, editorial ground, light |
| Signal | vermilion, red, orange | attention, urgency, product energy |
| Depth | cobalt, ultramarine, midnight blue | atmosphere, distance, digital/night tension |
| Light | cream, sodium yellow, restrained gold | focus, threshold, illumination |

Use only the roles that the source and concept need. Two dominant colours plus one interruption is often stronger than a full palette. Never make every accent equally saturated.

### Spatial behaviour

- Prefer one strong axis, path, beam, aperture, or diagonal relation.
- Use asymmetry with a clear counterweight rather than accidental imbalance.
- Let empty space create anticipation or focus; do not fill it with lines or labels merely because it is empty.
- Keep the product name in a meaningful position determined by the composition. The name is not a default top-left/bottom-right watermark.

### Material behaviour

| Concept | Suitable material | Avoid |
| --- | --- | --- |
| communication / archive | controlled halftone, offset drift, paper edge | random dirt and fake documents |
| screen / distance / night | scanline, restrained glow, optical blur | generic cyberpunk neon everywhere |
| threshold / memory | paper plane, cut edge, soft grain | blanket sepia and scrapbook clutter |
| geometry / product clarity | flat colour, crisp edge, measured shadow | texture used to hide weak structure |

Material must follow the visual thesis. Start clean, then add only the smallest useful amount.

## Source-derived motif translation

| Source evidence | Possible graphic translation | Question to answer |
| --- | --- | --- |
| telephone, dial, voice, sign | circular aperture, radial cut, signal block | What is being heard or connected? |
| microphone, stage, beam | spotlight cone, isolated vertical, deliberate floor plane | What is waiting to be voiced? |
| film strip, road, stairs, horizon | measured path, repeated frame, receding band | Where is the movement going? |
| building, window, doorway | nested rectangle, cutout, threshold plane | What is opening or being withheld? |
| face, eye, hair, grid | precise crop, window, modular split | What is being observed or reconstructed? |
| sign, poster, receipt, text block | typographic field, torn panel, evidence strip | Which supplied word is truly necessary? |
| shoes, clothing, silhouette, body line | figure-ground inversion, contour plane | What identity survives reduction? |

Use one row as the governing mechanism. Do not stack every available cue.

## Visual quality test

At thumbnail size, the viewer should be able to name:

1. the main graphic event;
2. the source anchor;
3. the colour tension;
4. the product identity, if it is part of the brief.

If the viewer only sees “a retro poster,” the brand system has not been resolved.
