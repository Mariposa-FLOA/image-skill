# Page-Flip Layout Archetypes

Use only the smallest archetype that makes the user's image sequence readable. These are composition decisions, not templates to stack together.

## Open spread

Use for two or three images. Establish a low three-quarter camera angle, make the left and right pages carry the main content, and let one right-side page lift toward the left. Best for portraits, artwork, and a small curated set.

## Lifted single sheet

Use for one hero image or when the user wants the page-turn idea to read immediately. Keep the hero image on a stable page and use one blank or partially revealed sheet as the action. The lifted sheet must not invent a second version of the hero.

## Editorial sequence

Use for four to six images. Show a dominant image on the open spread, with smaller but still readable page reveals behind it. The sequence should follow the input order and use spacing, not decorative labels, to indicate progression.

## Close page detail

Use when the source contains fine artwork, product packaging, or text that must stay readable. Reduce the amount of book context, enlarge one or two printed pages, and use the fold, edge, and shadow as the page-flip evidence. Do not ask an image model to redraw dense source text.

## Reset rule

If the result looks like a generic collage, remove props and extra pages. Return to one hero image, one page-turn gesture, one light direction, and one quiet surface. A clearer physical action is more valuable than additional decoration.
