# FLOA Mariposa 新编辑主义视觉系统

`floa-mariposa-visual-system` 是为产品 **FLOA Mariposa** 提炼的品牌视觉 Skill。它来自维护者提供的一组原创海报样本，提炼的是可复用的设计判断，不是把某一张海报复制成模板。

## 正式命名

- 产品名称：`FLOA Mariposa`
- 中文风格名：`FLOA Mariposa 新编辑主义视觉`
- 英文风格名：`FLOA Mariposa Neo-Editorial Visual Language`
- Skill slug：`floa-mariposa-visual-system`

“复古”只描述其中可能出现的印刷材质，不是整体风格；“拼贴”“Y2K”“赛博朋克”也只是局部方法，不能代替 FLOA Mariposa 的品牌视觉定位。

## 这个 Skill 能做什么

- 把用户提供的产品图、人物图、场景图或概念做成 FLOA Mariposa 品牌海报；
- 为一组海报提炼统一但不重复的品牌视觉系统；
- 制作抖音封面、轮播首图、宣传主视觉、编辑封面和系列海报；
- 根据源图选择大字、几何空间、剪影、聚光灯、路径、建筑开口、网格或物体隐喻；
- 用红橙、钴蓝、奶油白、黑色等方向性色域建立品牌气质；
- 在需要翻页时，把品牌视觉方向交给 `page-flip-showcase`，再完成可点击画册或 MP4 翻页。

## 从样本中提炼出的固定规则

### 品牌固定项

- `FLOA Mariposa` 是一个完整产品名称，默认保留准确拼写、大小写和空格；
- 品牌气质来自编辑结构、图形化叙事、空间关系和色彩秩序；
- 每张图只保留一个主要视觉事件；
- 文字、图像、色彩和留白必须属于同一个构图系统；
- 产品名不是固定左上角/右下角水印，位置由构图决定。

### 每张图可以变化的部分

- 源图主体和故事情绪；
- 主色场与强调色；
- 裁切、轴线、透视和留白；
- 产品名的字标位置和比例；
- 剪影、摄影、几何、拼贴和印刷材质的占比；
- 文案数量与节奏。

## 视觉语言

新版加入视觉方向选择器：先根据源图选择 `Signal`（信号）、`Threshold`（门槛）、`Orbit`（轨道）或 `Archive`（档案）中的一个主导方向，再决定颜色、字体、空间和材质。每张图只允许一个主方向加一个辅助动作，避免把所有视觉手段堆在一起。

同时加入视觉比例检查：主视觉重量约 45–65%，次级形状约 20–35%，强调色约 5–12%，尽量保留至少 15% 的安静区；默认不超过两套字体、三种字号和两种文字颜色。这些是审美检查线，不是固定模板。

### 色彩

色彩按角色使用，而不是套固定滤镜：

- 近黑/深蓝：墨色、结构、夜景和文字；
- 奶油白/骨色：纸张、留白和光；
- 红/橙：信号、能量和视觉冲突；
- 钴蓝/电蓝：距离、屏幕和空间深度；
- 黄色/浅金：聚光、入口和注意力焦点。

一张图通常使用两到四个主色。不要每张都使用相同的红蓝背景，也不要让所有颜色同时达到最高饱和度。

### 构图

优先构建：色彩场 → 主体锚点 → 一个几何/光线/路径关系 → 字标或标题 → 少量材质细节。

好的结果可以在缩略图中读出主视觉事件、源图主体和色彩冲突。随机箭头、坐标、边框、贴纸和假资料不能替代构图。

### 文字

大字可以成为墙面、地平线、入口、遮挡关系或画面重量；小字只承担真实信息和节奏。没有用户提供的内容时，不添加虚构日期、客户、奖项、功能、地点、编号或技术参数。

## 推荐调用

```text
请使用 $floa-mariposa-visual-system。
把我上传的图片做成 FLOA Mariposa 的品牌海报。
风格采用“新编辑主义视觉”，不要简单做成复古、Y2K 或赛博朋克。
请从源图提取一个视觉事件，使用结构化大字、方向性色彩和源图相关的几何关系。
保留主体和准确文字，先返回 test。
```

系列海报：

```text
请使用 $floa-mariposa-visual-system。
根据这组图片做 6 张 FLOA Mariposa 系列海报。
保持品牌统一，但每张改变源图隐喻、构图轴线和色彩关系，不要复制同一套背景模板。
先给出系列视觉策略和 test 方向。
```

## 导入给其他智能体

- Codex 长期使用：导入完整的 `skills/floa-mariposa-visual-system/`；
- WorkBuddy 或其他支持本地 Skill 的平台：导入同一目录，保留 `SKILL.md`、`references/`、`agents/` 和 `evals/`；
- 一次性使用：下载 `chat-ready/floa-mariposa-visual-system.md`，和源图一起上传，并说“请按附件执行”；
- 如果只支持提示词：粘贴完整 `SKILL.md`，不要只复制其中几段风格形容词。

## 交付边界

这个 Skill 负责 FLOA Mariposa 的视觉判断和图像/版式方向。宿主是否能真正生成图片、写入网页、渲染 MP4 或导出可编辑文件，取决于宿主工具；智能体必须如实报告实际输出模式。用户提供的原图、私人元数据和未授权素材不会自动进入公开仓库。
