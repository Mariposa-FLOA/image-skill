# Glitchy Glam Editorial Visual

`glitchy-glam-editorial-visual` 是一套面向人物、时尚、美妆、产品和社交媒体视觉的当代图片 Skill。

中文名称：**错位华丽编辑视觉**。

它的核心不是“加故障”，而是：

> 先让主体漂亮、清晰、有高级编辑感，再用一次有控制的错位制造记忆点。

它不会先看到“热门风格”就强行套用。先分析场景、景别、人物、物品、光线和留白，再判断这张图是否适合 Glitchy Glam；如果不适合，应切换到更合适的视觉 Skill。

## 适合做什么

- 时尚人物和美妆大片；
- 高光、冷色、异色和不对称造型；
- 产品的高级商业视觉；
- 抖音/小红书封面和品牌社交图；
- 数字与实体、光泽与粗粝、对称与错位之间的视觉冲突。

## 五种视觉断裂

每张图只选择一种主机制：

1. **色彩回声**：在轮廓或局部产生受控的双色偏移；
2. **故意不对称**：左右妆容、饰品、色彩或光线产生有设计的不一致；
3. **裁切错位**：用偏移裁切、分割平面或重复细节打断画面；
4. **高光断面**：用一块漆面、金属、湿润或反光表面改变阅读；
5. **数字/实体冲突**：让扫描、信号、印刷或界面感元素与真实材质发生一次关系。

最多再加一个很小的辅助提示。不能同时堆满屏 RGB、扫描线、镜像、霓虹、玻璃和 3D 特效。

## 实际制作顺序

~~~text
分析场景/景别/人物/物品
→ 分割主体与背景
→ 建立干净构图和光线
→ 对指定区域加色
→ 选择一种错位机制
→ 加准确文字
→ 整理 PSD 图层
~~~

人物近景要保护眼睛、鼻子、嘴唇、雀斑和发际线；全身或宽景要让错位跟随环境轴线；产品图要保护轮廓、包装文字和接触阴影。颜色只能进入选定的妆面、衣物、轮廓、光影或背景平面，不能把整张图统一染成“故障色”。文字默认不加；需要文字时使用准确的本地文字层或 SVG，不让图片模型猜字。

## 视觉层级

默认检查：

- 主体与华丽光线约占视觉重量的 50–65%；
- 错位机制约占 15–25%；
- 文字和辅助图形约占 10–20%；
- 尽量保留至少 15% 的安静空间。

这是审美检查线，不是固定模板。主体要先于效果被看见，效果要改变阅读而不是覆盖主体。

## 推荐调用

```text
请使用 $glitchy-glam-editorial-visual。
把我上传的人像做成错位华丽编辑视觉。
先保留人物清晰、好看和身份，再加入一次受控的不对称或色彩错位。
不要满屏 glitch、赛博朋克、Y2K 贴纸或随机扫描线。
先返回 test。
```

产品图：

```text
请使用 $glitchy-glam-editorial-visual。
把我的产品做成高级、时髦、适合社交媒体的商业视觉。
可以使用冷蓝和高光，但不能改变产品形状、包装文字或材质逻辑。
只选择一个视觉断裂，保留产品清晰可读。
```

## 与现有 Skill 的关系

- `floa-mariposa-visual-system`：当 FLOA Mariposa 品牌系统是主任务时使用；
- `glitchy-glam-editorial-visual`：当“当代时髦 + 一次受控错位”是主视觉机制时使用；
- `optical-refraction-visual`：当真实折射、镜面或透明介质是主任务时使用；
- `y2k-street-cutout-poster`：当街头剪裁、贴纸和早期数字杂志语言是主任务时使用；
- `poster-layered-psd-export`：当需要 Photoshop 分层文件时作为后续交付工具使用。

不要同时让多个主视觉 Skill 接管同一张图；先选一个主机制。

## 交付边界

它可以指导或生成静态图片、社交封面和产品视觉。是否能输出 PSD、网页或视频，取决于后续宿主工具；智能体必须如实说明实际生成的文件类型。文字如果要求准确，应在本地排版或 SVG 阶段完成，不要依赖图片模型猜字。
