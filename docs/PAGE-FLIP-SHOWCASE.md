# `page-flip-showcase` 功能说明

`page-flip-showcase` 是一个把用户提供的照片、海报、产品图、作品图或截图组织成“翻页作品集”的视觉 Skill。它不只是给图片套一个书本边框，而是先分析源图，再决定色彩、拼贴、页面层级和翻页方式。

## 一句话定位

把一组真实图片变成有编辑设计感的静态翻页主视觉、可操作的电子画册，或真正逐页翻动的 MP4 视频，同时尽可能保留源图中的人物、产品、版式和文字。

## 三种输出模式

### 1. 静态展示图

适合“做一张翻页展示图”“做成画册效果”“先看视觉方向”。

- 输出一张 3:4 或按源图推断的静态主视觉；
- 图片被放在真实纸页、画册或作品集结构中；
- 画面包含一个明确的翻起页面、纸张厚度、透视和接触阴影；
- 不把静态图说成 GIF 或视频。

### 2. 可操作电子画册

适合“可以点击一篇一篇翻”“我想手动翻页”“做一个电子画册”。

- 一次只显示一页；
- 点击上一页/下一页可以前进或后退一页；
- 支持键盘 `←`、`→`、空格；
- 支持触屏左右滑动；
- 翻页进行中会锁定重复操作；
- 第一页和最后一页的边界按钮状态正确；
- 图片作为本地资源保存，避免上传或依赖远程图片。

### 3. 自动翻页视频

适合“做成 MP4”“自动一页一页播放”“我要真正的翻页动画”。

- 使用本地 HyperFrames + FFmpeg 渲染；
- 每页先停留，再围绕垂直书脊做 `rotationY` 翻页；
- 当前页面翻走后露出下一页，不用硬切冒充翻页；
- 最后一页保持到视频结束；
- 默认不添加音乐或翻页音效，除非用户另外要求并且确实生成、混音和验收；
- 交付前检查尺寸、帧率、时长、帧数和翻页中间帧。

## 自适应视觉背景

这是本 Skill 的核心美学能力之一。背景不能固定使用同一套红蓝色块或网页式线框。

每一张海报先提取：

1. 两到四个主色，以及它们在画面中的角色；
2. 一个真实的视觉母题，例如电话拨号盘、票据竖条、拱形窗、箭头路径、巨大字块、面部网格或产品轮廓；
3. 海报的构图重心、留白位置、字体占比和材质感觉；
4. 适合被延展到背景中的局部纹理或图像碎片。

然后按图层建立背景：

```text
色彩场
  ↓
最多两个源图局部拼贴碎片
  ↓
剪纸 / 纸片 / 撕裂边缘 / 色块
  ↓
少量定位记号或身份短线
  ↓
页面主体
```

线条只是辅助层。如果拼贴已经承担了视觉重点，就不再添加完整矩形框、长竖轴线或装饰性底线。用户提供的固定标识，例如左上 `FLOA`、右下 `Mariposa`，作为身份层使用，不能被占位词替换。

## 输入约定

推荐提供：

- 一张或多张图片；
- 图片的阅读顺序；
- 输出模式：静态图、交互画册或 MP4；
- 画幅比例和用途（如果有）；
- 必须保留的主体、文字、Logo、包装或版式；
- 固定身份文字，例如左上角名称、右下角系列名称；
- 不希望出现的装饰、颜色、符号或风格。

如果用户没有指定顺序，就按上传顺序。没有图片时不虚构图片；没有指定比例时，先观察源图方向和构图再决定。

## 源图保护

- 不拉伸图片，不把竖图硬改成横图；
- 不随意改变人物脸型、产品形状、手部、衣服和主体关系；
- 海报中的关键文字、Logo、包装信息和 UI 字段尽量保留原图像素；
- 局部源图拼贴只能作为背景层，不能复制成另一张完整海报；
- 不为了追求“艺术感”而添加不存在的人、产品、品牌或信息；
- 不把棋盘格、假透明背景或生成错误当成真实分层。

## 文件结构

```text
skills/page-flip-showcase/
├── SKILL.md

├── references/
│   ├── interactive-video-contract.md
│   └── layout-archetypes.md
```

`SKILL.md` 是运行规则；`references/` 保存构图和交互/视频契约；`scripts/` 保存可重复的静态合成工具。测试用例用于维护和回归，不是用户源图素材。

## 调用示例

### 静态图

```text
请使用 $page-flip-showcase。
把这 3 张作品图做成一本正在翻页的艺术家作品集，先给我 test，不要归档。
```

### 电子画册

```text
请使用 $page-flip-showcase。
做成可以点击、一篇一篇翻的电子画册，一次显示一页，支持左右键和手机滑动。
```

### MP4

```text
请使用 $page-flip-showcase。
把这些海报按上传顺序做成真正的翻页 MP4，每页停留一下再翻到下一页。
背景根据每张海报的色彩和元素做拼贴，不要套固定线框。
左上角写 FLOA，右下角写 Mariposa。
```

## 验收标准

静态图看：主页面清楚、翻页动作明确、背景与源图有关、没有假文案。

电子画册看：是否真的一次只翻一页、边界按钮是否正确、触屏/键盘是否可用。

MP4 看：是否有真实翻页中间帧、8 张图是否按顺序出现、是否有黑帧/跳帧、最后是否停在最后一页，以及是否如实说明有没有声音。

## 当前边界

这个 Skill 负责视觉编排和本地展示/渲染规则，不自动替用户上传图片到第三方服务，也不默认生成付费模型内容。视觉成品是否“接受”仍由用户确认；`test` 不等于最终交付。
