# Example image and video terms

Unless a separate notice is attached to an individual file, the images and videos in `examples/` are demonstration assets for this repository.

They may be viewed and linked to as documentation examples. They are not licensed for resale, stock redistribution, model training, dataset inclusion, or use as a substitute for the underlying Skill. Do not extract people, logos, source photographs, or visual identity elements from an example and present them as your own.

`examples/page-flip-showcase.mp4` is a public demonstration video authorized for this repository by the maintainer. It contains the maintainer-provided poster pages and is shared for Skill preview and documentation only; the same restrictions apply.

`examples/floa-mariposa-visual-system.png` is one public example authorized for this repository by the maintainer. It is shared for Skill preview and documentation only; the same restrictions apply. The remaining FLOA Mariposa reference posters are not redistributed here.

The retired chromatic-glass Skill and its historical image are not included in this release.
